## Open issues / decisions for the authors (most important first)
1. DISCRETE CONVERGENCE FOR p<2. Both the analyst (ANALYST_REPORT C.4(ii)) and I note that on a fixed mesh the iteration
   is finite-dimensional ADMM with an existing saddle point for every p_T > 1, so standard ADMM theory gives convergence
   for all p>1 at fixed h. Per the brief ("NO claim for p<2") the paper states only the facts (Remark 3.5: discrete saddle
   point exists, iteration is ADMM) and does not claim convergence. If the PI agrees, this could become a Proposition
   (proof sketch in ANALYST_REPORT C.4(ii)); then the Open question should be restricted to the continuous setting and
   to h-uniform rates.
2. Theorem 3.2 (Glowinski, Ch. VI, Thm 5.1): the hypotheses (H1) B injective with closed range, (H2) saddle point,
   (H3) 0 < rho < (1+sqrt5) r / 2 in a Hilbert setting are stated from memory of Glowinski / Fortin-Glowinski; neither
   I nor the analyst had the book. MUST be checked against the book (theorem number and exact hypotheses).
3. Corollary 3.3 adds an explicit regularity assumption |grad u|^{p(x)-1} in L^2 (needed for a saddle point in L^2);
   the old paper simply assumed a saddle point. Check that this is acceptable.
4. Grants (PIP 2015, PICT 2016) kept in \thanks and acknowledgements; update if needed.
5. Timings: one sentence only (sandbox, 2 cores), no comparison with other implementations.
